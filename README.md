# Soccer Agent Dynasty — legal & support pages

The public privacy policy, terms of use and support pages for the iPhone game
**Soccer Agent Dynasty**, served via GitHub Pages so App Store Connect has a
stable URL to link.

These files are **generated** — the markdown sources live in the game repo
(`PRIVACY.md`, `TERMS.md`, `SUPPORT.md`) and are rendered by
`scripts/build-pages.mjs`. Edit them there, rebuild, and copy the output here;
do not hand-edit the HTML.
